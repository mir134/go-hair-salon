## MVP 完成定义

以下流程全部成功才算第一阶段完成：

### 流程 A

```
管理员登录
→ 新增员工
→ 新增服务项目
→ 新增客户
```

### 流程 B

```
手机登录
→ 搜索客户
→ 查看客户
→ 快速消费
→ 生成消费记录
```

### 流程 C

```
客户充值
→ 余额增加
→ 查看余额流水
→ 使用余额消费
→ 余额减少
```

### 流程 D

```
电脑查看 Dashboard
→ 查看营业额
→ 查看客户
→ 查看员工数据
```

### 流程 E

```
管理员备份
→ 修改数据
→ 从备份恢复
→ 数据可正常使用
```
